


\section{Problem Formulation}
\label{subsec:problem_formulation}
\subsection{QHD: hyperdimensional Q-learning for continuous-state control}
We now describe how hyperdimensional representations are used to approximate action-value functions in continuous-state, discrete-action control. Agent $i$ selects an HDC encoder
\begin{equation}
\Phi_i:\mathcal{S}\to\mathbb{K}^{D_i},
\qquad \mathbb{K}\in\{\mathbb{R},\mathbb{C}\},
\label{eq:phi_i}
\end{equation}
which maps continuous states $s\in\mathbb{R}^{d}$ to hypervectors. For each action $a\in\mathcal{A}$, the agent maintains a parameter hypervector $\mathbf{w}_{i,a}\in\mathbb{K}^{D_i}$ and defines the Q-function approximation
\begin{equation}
Q_i(s,a) \;\triangleq\; \Re\!\left(\langle \Phi_i(s),\,\mathbf{w}_{i,a}\rangle\right).
\label{eq:qhd_q}
\end{equation}
Stacking parameters across actions yields $W_i [\mathbf{w}_{i,a}]_{a\in\mathcal{A}}\in\mathbb{K}^{D_i\times|\mathcal{A}|}$ and $Q_i(s,\cdot)=\Re(\Phi_i(s)^{\mathrm{H}} W_i)$. Although the encoder $\Phi_i(\cdot)$ may be highly nonlinear in $s$,
the model is \emph{linear in parameters}. This linearity is the key structural property we will exploit for federated learning.


To stabilize training, QHD uses a delayed target model
$Q_i^-$ with parameters $W_i^-$, copied from $W_i$ every
$\tau$ episodes \citep{ni2022qhd}. Given a replayed transition
$(s,a,r,s')$ sampled from the local replay buffer, the
bootstrapped TD target is:
\begin{equation}
    y
    \;=\;
    r \;+\; \gamma\,
    \Re\!\Bigl(\Phi_i(s')^{\mathrm{H}}
    \mathbf{w}^-_{i,\,a^*}\Bigr),
    \qquad
    a^* = \arg\max_{a'\in\mathcal{A}} Q_i(s',a'),
    \label{eq:target}
\end{equation}
where the greedy action $a^*$ is selected by the \emph{current}
model $W_i$ while its value is evaluated by the \emph{delayed}
model $W_i^-$. This decoupling prevents the overestimation
bias inherent in single-model Q-learning.


The update in \eqref{eq:qhd_update} is a semi-gradient
stochastic approximation to the Bellman optimality equation.
Because the model is linear in parameters,
the gradient of $Q_i(s,a)$ with respect to $\mathbf w_{i,a}$ is
$\nabla_{\mathbf w_{i,a}} Q_i(s,a) = \Phi_i(s)$.
Therefore, minimizing the squared TD error
$\tfrac12 (y - Q_i(s,a))^2$
by stochastic gradient descent yields:
\begin{equation}
    \mathbf{w}_{i,a}
    \;\leftarrow\;
    \mathbf{w}_{i,a}
    \;+\;
    \eta\,\delta\,\Phi_i(s),
    \label{eq:qhd_update}
\end{equation}
where $\delta = y - Q_i(s,a)$

\subsection{Federated value learning as a global objective}
We consider $N$ agents learning concurrently, each with a private replay buffer $\mathcal{D}_i$.

Federated reinforcement learning seeks to aggregate local value knowledge into a global representation without centralizing data, as data sharing is impossible due to privacy constraints, communication limitations, or latency.




\paragraph{Federation as function-space averaging (synchronization operator).}
Each client $i$ learns a local action-value model $Q_i$ from private off-policy replay using QHD-style updates. The server does not access client data or optimize client Bellman losses; instead, it periodically performs a \emph{synchronization} step that aggregates the learned client models into a global teacher in \emph{function space}. Let $\mu$ denote an agreement/query distribution over state--action pairs (instantiated in our method by a small shared anchor set), and let $\pi_i\ge 0$ be federation weights with $\sum_{i=1}^N \pi_i=1$ (e.g., proportional to client data volume).
Given fixed client models $\{Q_i\}_{i=1}^N$, the server defines the global teacher $Q^{\mathrm{glob}}$ as the unique minimizer of
\begin{equation}
Q^{\mathrm{glob}} \;\in\; \arg\min_{Q} \sum_{i=1}^N \pi_i\, E_{(s,a)\sim\mu}\!\left[\big(Q_i(s,a)-Q(s,a)\big)^2\right].
\label{eq:fed_sync}
\end{equation}
This objective is to combine the clients' knowledge in a shared output space rather than in an (often incompatible) parameter space.  The minimizer is the weighted pointwise average (in $\mu$-expectation),
\begin{equation}
Q^{\mathrm{glob}}(s,a) \;=\; \sum_{i=1}^N \pi_i\,Q_i(s,a) \qquad (\mu\text{-a.e.}).
\label{eq:qglob_avg}
\end{equation}

The function-space synchronization objective in \eqref{eq:fed_sync} unifies several classical cases. In the tabular setting, sharing Q-tables achieves exact function-space agreement. In the linear-parameterization setting—of which QHD is the primary instance—parameter averaging coincides exactly with function-space averaging, enabling efficient closed-form federation. For nonlinear approximators such as deep Q-networks, however, parameter averaging is a heuristic that operates in weight space rather than function space, and is undefined when clients use different architectures or dimensions.



Existing federated RL systems face two central obstacles:{(1) No closed-form, fast synchronization under nonlinear models.} For nonlinear approximators, federated aggregation generally cannot be computed in closed form; client-side assimilation requires iterative optimization, which is expensive and unstable under moving RL targets. {(2) Model heterogeneity breaks parameter aggregation.} Classical federated methods assume a shared parameterization. If clients use different encoders, different architectures, or different parameter dimensions $D_i$, parameter averaging is undefined or semantically meaningless. Such heterogeneity is unavoidable in real autonomous systems.



\section{FedQHD: Function-Space Federation with Closed-Form Translation}
\label{sec:methodology}
The federation objective in Eq.~\eqref{eq:fed_sync} defines a synchronization operator that aggregates client knowledge in \emph{function space}, independently of how local value functions are parameterized or learned. In this section, we show that QHD provides a uniquely favorable structure for realizing this operator efficiently and exactly.

The key enabling property is that, although QHD induces expressive nonlinear approximation over continuous state spaces through the encoder $\Phi_i(\cdot)$, the resulting Q-functions are \emph{linear in parameters}. This linearity allows the federation objective to be solved in closed form when representations are shared, and to be extended to heterogeneous encoders via closed-form translation operators. We first analyze the homogeneous-encoder regime, where the federation operator admits an exact solution that coincides with parameter averaging. This case clarifies the relationship between FedQHD and FedAvg and motivates the general heterogeneous construction that follows.

\subsection{Fed-QHD with Homogeneous Encoders}
\label{sec:fedqhd_homogeneous}

\begin{equation}
Q^{\mathrm{glob}}(s,a) = \langle \Phi(s), w^{\mathrm{glob}}_a \rangle,
\qquad
W^{\mathrm{glob}} \in \mathbb{K}^{D \times |\mathcal{A}|}.
\label{eq:qhd_global}
\end{equation}
Substituting \eqref{eq:qhd_local} and \eqref{eq:qhd_global} into \eqref{eq:fed_sync_recall} yields the quadratic objective
\begin{equation}
\min_{W^{\mathrm{glob}}}\sum_{i=1}^N \pi_i E_{(s,a)\sim\mu} \big[ \langle \Phi(s), (W_i - W^{\mathrm{glob}})_{:,a} \rangle^2\big].
\label{eq:fed_quad}
\end{equation}
Let $\Sigma_\mu = \E_{(s,a)\sim\mu}[\Phi(s)\Phi(s)^\mathrm{H}]$ denote the
feature covariance induced by the agreement distribution.
Then \eqref{eq:fed_quad} can be written as
\begin{equation}
\min_{W^{\mathrm{glob}}} \sum_{i=1}^N \pi_i \sum_{a\in\mathcal{A}} (W_{i,a}-W^{\mathrm{glob}}_a)^\mathrm{H} \Sigma_\mu (W_{i,a}-W^{\mathrm{glob}}_a),
\label{eq:fed_quad_cov}
\end{equation}
which is a strictly convex quadratic problem whenever $\Sigma_\mu \succ 0$, with solution as:
\begin{equation}
W^{\mathrm{glob}} = \sum_{i=1}^N \pi_i W_i.
\label{eq:exact_avg}
\end{equation}

Although the quadratic objective in
\eqref{eq:fed_quad_cov} depends on the feature covariance
$\Sigma_\mu = \mathbb E_\mu[\Phi(s)\Phi(s)^{\mathrm H}]$,
the minimizer does not.
Thus, in the homogeneous linear case,
function-space averaging coincides exactly with
parameter averaging,
independently of the anchor distribution $\mu$.
Importantly, the server never needs access to
raw state samples or $\Sigma_\mu$ itself.


\subsection{Fed-QHD with Heterogeneous Encoders}
\label{sec:fedqhd_heterogeneous}
Consider a case where each client may use a different hyperdimensional encoder, different kernel hyperparameters, and even a different feature dimension.  In this setting, parameter averaging is undefined, but function-space consensus remains meaningful. Client $i$ uses an encoder \(\Phi_i:\mathcal{S}\to\mathbb{K}^{D_i}, \mathbb{K}\in\{\mathbb{R},\mathbb{C}\},\)
where both the dimension $D_i$ and encoder design (random seed, binding/permutation rules, kernel scale, quantization)
may differ across clients. 

To define federation operationally, we instantiate the agreement distribution $\mu$ by a finite \emph{server-defined anchor set}. Let $\mathcal{S}_{\mathrm{ref}}=\{s_1,\dots,s_m\}$ denote a fixed set of reference states generated independently of all clients. In many autonomy domains, the server can obtain $\mathcal{S}_{\mathrm{ref}}$ from a simulator/digital twin by executing a random or exploratory policy and logging visited states without rewards, actions, or trajectories.

Each client computes its anchor predictions $Q^{\mathrm{ref}}_i[j,a] \;\defeq\; Q_i(s_j,a),\, Q^{\mathrm{ref}}_i\in\mathbb{R}^{m\times|\mathcal{A}|},$
and the server forms the function-space consensus teacher
$Q^{\mathrm{glob}}_{\mathrm{ref}}=\sum_{i=1}^N \pi_i\, Q^{\mathrm{ref}}_i, \sum_{i=1}^N \pi_i=1,\;\pi_i\ge 0$,
which is the unique minimizer of the anchor consensus objective
$\min_{Q\in\mathbb{R}^{m\times|\mathcal{A}|}} \sum_i \pi_i \|Q^{\mathrm{ref}}_i - Q\|_F^2$.


For each client $i$, define the \emph{anchor feature matrix} by stacking encoded anchor states:
\begin{equation}
X_i \;=\; 
\begin{bmatrix}
\Phi_i(s_1) \\
\Phi_i(s_2) \\
\vdots \\
\Phi_i(s_m)
\end{bmatrix}
\in \mathbb{K}^{m \times D_i}.
\label{eq:anchor_matrix_i}
\end{equation}
The local Q-function evaluations on the anchor set can then be written compactly as
\begin{equation}
Q^{\mathrm{ref}}_i = \Re(X_i W_i),
\qquad W_i = [\mathbf{w}_{i,a}]_{a\in\mathcal{A}} \in \mathbb{K}^{D_i \times |\mathcal{A}|}.
\label{eq:anchor_q_matrix_form}
\end{equation}

We seek a client-side parameter matrix $W^{\mathrm{glob}}_i\in\mathbb{K}^{D_i\times|\mathcal{A}|}$ that enables client $i$ to reproduce the global teacher $Q^{\mathrm{glob}}_{\mathrm{ref}}$ as closely as possible using its own encoder $\Phi_i$. This leads to the \emph{regularized least-squares compilation problem}:
\begin{equation}
W^{\mathrm{glob}}_i \;=\; \arg\min_{W \in \mathbb{K}^{D_i \times |\mathcal{A}|}} 
\left\|X_i W - Q^{\mathrm{glob}}_{\mathrm{ref}}\right\|_F^2 
+ \lambda \|W\|_F^2,
\label{eq:regularized_compilation}
\end{equation}
where $\lambda \ge 0$ is a regularization parameter that controls model complexity and stabilizes the solution when the anchor set is small ($m < D_i$) or when $X_i$ is ill-conditioned.


Problem~\eqref{eq:regularized_compilation} is a convex quadratic optimization problem in $W$ with a unique global minimizer. Taking the gradient with respect to $W$ and setting it to zero yields the regularized normal equations:
\begin{equation}
\left(X_i^\mathrm{H} X_i + \lambda I_{D_i}\right) W^{\mathrm{glob}}_i = X_i^\mathrm{H} Q^{\mathrm{glob}}_{\mathrm{ref}}.
\label{eq:normal_equations}
\end{equation}
When $\lambda > 0$ or when $X_i^\mathrm{H} X_i$ is full rank, the system~\eqref{eq:normal_equations} is invertible, yielding the explicit solution:
\begin{equation}
W^{\mathrm{glob}}_i = \left(X_i^\mathrm{H} X_i + \lambda I_{D_i}\right)^{-1} X_i^\mathrm{H} Q^{\mathrm{glob}}_{\mathrm{ref}}.
\label{eq:ridge_solution}
\end{equation}
In the unregularized limit $\lambda \to 0$, this reduces to the Moore-Penrose pseudoinverse solution:
\begin{equation}
W^{\mathrm{glob}}_i = X_i^\dagger Q^{\mathrm{glob}}_{\mathrm{ref}},
\qquad X_i^\dagger = (X_i^\mathrm{H} X_i)^{-1} X_i^\mathrm{H},
\label{eq:pseudoinverse_solution}
\end{equation}
provided $\mathrm{rank}(X_i) = \min(m, D_i)$.



Applying the Woodbury identity to
\eqref{eq:ridge_solution} yields the equivalent
dual representation:
\begin{equation}
W^{\mathrm{glob}}_i
=
X_i^{\mathrm H}
(G_i + \lambda I_m)^{-1}
Q^{\mathrm{glob}}_{\mathrm{ref}},
\qquad
G_i = X_i X_i^{\mathrm H}.
\label{eq:dual_ridge}
\end{equation}
Thus, compilation depends only on the
$m \times m$ Gram matrix $G_i$,
whose entries are
$[G_i]_{jk}
=
\langle \Phi_i(s_j), \Phi_i(s_k)\rangle$.
This reveals that heterogeneous FedQHD
operates as a kernel ridge regression step
on the anchor set.

\section{Projection Residual as a Structural Heterogeneity Measure}
\label{sec:projection_residual}

We formalize the least-squares compilation residual induced by heterogeneous client representations and show that it admits an exact operator form with a clear geometric and optimization-theoretic interpretation. This residual isolates irreducible representation mismatch across clients and provides a principled diagnostic for capacity-limited transfer in heterogeneous federated reinforcement learning.


\begin{proposition}[Irreducible anchor mismatch]
\label{prop:irreducible}
Assume $\lambda=0$ and let $P_i$ denote the orthogonal projector onto
$\mathrm{col}(X_i)\subseteq\mathbb{K}^m$. Then
\[
\min_{W\in\mathbb{K}^{D_i\times|A|}}\|X_iW-Q^{\mathrm{glob}}_{\mathrm{ref}}\|_F
\;=\;\|(I-P_i)Q^{\mathrm{glob}}_{\mathrm{ref}}\|_F.
\]
In particular, $\|(I-P_i)Q^{\mathrm{glob}}_{\mathrm{ref}}\|_F=0$ if and only if
$Q^{\mathrm{glob}}_{\mathrm{ref}}\in\mathrm{col}(X_i)^{|A|}$, i.e., the teacher is
exactly representable by client $i$ on the anchor set.
\end{proposition}


\begin{proposition}[Residual amplification via subspace misalignment]
\label{prop:heterogeneity}
Assume $\lambda=0$ and let $P_i$ denote the orthogonal projector onto
$\mathrm{col}(X_i)$. Suppose the anchor teacher is formed as a convex
combination
\(
Q^{\mathrm{glob}}_{\mathrm{ref}}
=
\sum_{j=1}^N \pi_j Q^{(j)}_{\mathrm{ref}},
\qquad
Q^{(j)}_{\mathrm{ref}}\in\mathrm{col}(X_j),
\quad
\sum_j\pi_j=1.
\)
Then the irreducible mismatch for client $i$ satisfies
\[
R_{i,0}= (I-P_i)Q^{\mathrm{glob}}_{\mathrm{ref}} = \sum_{j\neq i}\pi_j (I-P_i)Q^{(j)}_{\mathrm{ref}}, \text{ with the bound } \|R_{i,0}\|_F \;\le\; \sum_{j\neq i}\pi_j \sin(\theta_{ij}) \,\|Q^{(j)}_{\mathrm{ref}}\|_F,
\]
where $\theta_{ij}$ is the largest principal angle between the subspaces
$\mathrm{col}(X_i)$ and $\mathrm{col}(X_j)$.
\end{proposition}




\subsection{Invisibility of the Projection Residual in Function Space}
\label{subsec:residual_invisibility}

In any heterogeneous federated learning system, aggregating models with
mismatched representational capacity produces a projection residual: the
component of the global teacher that falls outside a given client's
function class. This residual is a universal structural artifact of model
heterogeneity, arising whether the underlying approximators are linear,
kernel-based, or neural. The central question is: \emph{does this
residual propagate into the compiled model's predictions, or is it
silently discarded?}

The following theorem
shows that the projection residual
$R_{i,0} = (I - P_i)Q^{\mathrm{glob}}_{\mathrm{ref}}$ is
\emph{completely invisible} to the compiled Q-function at every
state---not just on the anchor set. The compiled solution
$W^{\mathrm{glob}}_i(\lambda)$ encodes only the in-subspace component
$P_i Q^{\mathrm{glob}}_{\mathrm{ref}}$, as if the residual had never
existed.

This has a dual interpretation:
\begin{enumerate}[label=(\roman*)]
    \item \textbf{No corruption:} The residual does not distort
    client~$i$'s predictions at any state $s \in \mathcal{S}$.
    \item \textbf{Silent information loss:} Knowledge contributed by
    other clients $j \neq i$, whose anchor predictions
    $Q^{(j)}_{\mathrm{ref}}$ have components in
    $\mathrm{col}(X_i)^{\perp}$, is irrecoverably discarded during
    compilation. The global server faithfully aggregates all clients'
    knowledge, but each client can only absorb the portion that lies
    within its own representable subspace.
\end{enumerate}

\begin{theorem}[Invisibility of the projection residual]
\label{thm:invisibility}
Let $W^{\mathrm{glob}}_i(\lambda)$ be the ridge solution
\eqref{eq:ridge_solution} for any $\lambda \geq 0$, and let
$R_{i,0} = (I - P_i)Q^{\mathrm{glob}}_{\mathrm{ref}}$. Then for
every $s \in \mathcal{S}$, $a \in \mathcal{A}$:
\begin{equation}
    Q_i\!\left(s, a;\, W^{\mathrm{glob}}_i(\lambda)\right)
    \;=\;
    \mathbf{k}_i(s)^{\!\top}
    (G_i + \lambda I_m)^{-1}
    P_i\, Q^{\mathrm{glob}}_{\mathrm{ref},a},
    \label{eq:representer_visible}
\end{equation}
where $\mathbf{k}_i(s) = X_i\Phi_i(s) \in \mathrm{col}(X_i)$ and
$G_i = X_i X_i^{\mathrm{H}}$. In particular,
\begin{equation}
    \mathbf{k}_i(s)^{\!\top}(G_i + \lambda I_m)^{-1} R_{i,0,a} = 0
    \qquad \forall\, s \in \mathcal{S},\; \forall\, \lambda \geq 0.
    \label{eq:residual_zero}
\end{equation}
\end{theorem}

\begin{proof}[Proof sketch]
The key step is decomposing the global teacher into its in-subspace component
($P_i Q^{\mathrm{glob}}_{\mathrm{ref},a} \in \mathrm{col}(X_i)$) and its residual
($R_{i,0,a} \in \ker(G_i)$). Since $(G_i + \lambda I_m)^{-1}$ preserves the eigenspaces of $G_i$,
the vector $(G_i+\lambda I_m)^{-1}R_{i,0,a}$ remains in $\ker(G_i)$,
which is orthogonal to $\mathbf{k}_i(s) \in \mathrm{col}(X_i)$.
Hence~\eqref{eq:residual_zero} holds. Full proof in Appendix~\ref{app:proof_invisibility}.
\end{proof}

\begin{remark}[From general heterogeneity to FedQHD]
The projection residual  arises
whenever a heterogeneous client must internalize a global model that
exceeds its representational capacity. In general nonlinear DRL methods, quantifying this residual and understanding
its effect on the compiled model requires iterative optimization and
lacks closed-form characterization. The linearity-in-parameters
structure of QHD is what makes the invisibility result exact and
analytically tractable. Theorem~\ref{thm:invisibility} thus provides
a precise lens through which to study the cost of heterogeneity: the
compiled model is never \emph{corrupted}, but it may be
\emph{incomplete}. The magnitude of this information loss is governed
by the subspace misalignment $\sin(\theta_{ij})$ between client
encoders (Proposition~\ref{prop:heterogeneity}), which we bound
in the federation gap analysis of
Section~\ref{subsec:fed_gap}.
\end{remark}



\subsection{Federated Representation Mismatch in Q-learning}
\label{subsec:fed_gap}

In federated reinforcement learning, each client performs value learning in its own representation space.
When these representations differ, the global aggregation step implicitly performs cross-subspace distillation. To analysis how does representation heterogeneity distort the learned Q-functions in federated control, we characterise the gap between the \emph{best linear approximation
of $Q^*$ achievable by client $i$'s encoder} and the compiled
FedQHD output.  The analysis requires no assumption on the
convergence of Q-learning with function approximation—an open
problem in continuous state spaces \citep{baird1995residual,
van_hasselt2018deep}—and instead relies entirely on the geometric
properties of the encoder subspaces $\{\mathcal{F}_i\}$
established in Section~\ref{sec:projection_residual}.

%───────────────────────────────────────────────────────────────

\subsubsection{Federation Gap Definitions and Assumptions}


\begin{definition}[Principal angles in $\mathcal{H}$]
\label{def:principal_angle}
Let $\mathcal{F}_i,\mathcal{F}_j\subseteq\mathcal{H}$ be closed
subspaces with $\mathcal{H}$-orthogonal projectors
$\Pi_i,\Pi_j$.
The $k$-th principal angle
$\theta_{ij,k}\in[0,\pi/2]$ is:
\begin{equation}
    \cos(\theta_{ij,k})
    =
    \sup_{\substack{f\in\mathcal{F}_i,\;g\in\mathcal{F}_j\\
    \|f\|_{\mathcal{H}}=\|g\|_{\mathcal{H}}=1,\\
    f\perp_{\mathcal{H}} f_1,\ldots,\;
    g\perp_{\mathcal{H}} g_1,\ldots}}
    \langle f,g\rangle_{\mathcal{H}}.
\end{equation}
The largest principal angle
$\theta_{ij}\defeq\max_k\theta_{ij,k}$ satisfies
$\|(I-\Pi_i)\Pi_j\|_{\mathcal{H}\to\mathcal{H}}
=\sin(\theta_{ij})$.
Since $\mathcal{F}_i$ is spanned by $D_i$ feature functions,
all angles are well-defined and the supremum is attained.
Restricted to the anchor set $\mathcal{S}_{\mathrm{ref}}$,
$\theta_{ij}$ reduces to the largest principal angle between
$\mathrm{col}(X_i)$ and $\mathrm{col}(X_j)$ in
$\mathbb{K}^m$ (Proposition~\ref{prop:heterogeneity}).
\end{definition}

\begin{definition}[RKHS regression oracle]
\label{def:oracle}
For each client $i$, define the \emph{oracle parameter}
$\hat{W}_i$ and \emph{oracle Q-function} $\hat{Q}_i$ by:
\begin{equation}
    \hat{W}_i
    \;\defeq\;
    \arg\min_{W\in\mathbb{K}^{D_i\times|\mathcal{A}|}}
    \sum_{a\in\mathcal{A}}
    \bigl\|
    \Re(\Phi_i(\cdot)^{\mathrm{H}}W_{:,a})
    - Q^*(\cdot,a)
    \bigr\|_{\mathcal{H}}^2,
    \qquad
    \hat{Q}_i(\cdot,a)
    \;\defeq\;
    \Re(\Phi_i(\cdot)^{\mathrm{H}}\hat{W}_{i,a}).
    \label{eq:oracle_def}
\end{equation}
Since $\mathcal{F}_i
=\{\Re(\Phi_i(\cdot)^{\mathrm{H}}w):w\in\mathbb{K}^{D_i}\}$
is a finite-dimensional subspace of
$\mathcal{H}$, the minimizer exists and is unique.
By the Hilbert projection theorem, $\hat{Q}_i(\cdot,a)$ is
the $\mathcal{H}$-orthogonal projection of $Q^*(\cdot,a)$
onto $\mathcal{F}_i$:
\begin{equation}
    \hat{Q}_i(\cdot,a)
    \;=\;
    \Pi_i\,Q^*(\cdot,a),
    \label{eq:oracle_is_proj}
\end{equation}
where $\Pi_i:\mathcal{H}\to\mathcal{F}_i$ is the
$\mathcal{H}$-orthogonal projector.
The \emph{representation error} of client $i$ is the
minimum achievable regression loss:
\begin{equation}
    \varepsilon_i^{\mathrm{rep}}
    \;\defeq\;
    \max_{a\in\mathcal{A}}
    \|Q^*(\cdot,a)-\hat{Q}_i(\cdot,a)\|_{\mathcal{H}}
    \;=\;
    \max_{a\in\mathcal{A}}
    \|(I-\Pi_i)Q^*(\cdot,a)\|_{\mathcal{H}}.
    \label{eq:rep_error}
\end{equation}

For HDC encoders with RBF kernels,
$\mathbb{E}[\varepsilon_i^{\mathrm{rep},\infty}]
=O(B/\sqrt{D_i})$ \citep{rudi2017generalization}.
\end{definition}





\begin{assumption}[Feature covariance]
\label{assum:feature_cov}
For each client $i$:
\begin{enumerate}[label=(\roman*)]
    \item \textup{(Positive definiteness)}
    $\Sigma_i \defeq \mathbb{E}_{s\sim\nu_i}
    [\Phi_i(s)\Phi_i(s)^{\mathrm{H}}]
    \succ 0$;
    \item \textup{(Boundedness)}
    $\|\Phi_i(s)\|_2 \leq 1$
    for all $s \in \mathcal{S}$.
\end{enumerate}
Condition~(i) is used in Lemma~\ref{lem:oracle_exist} to guarantee
existence and uniqueness of $\hat{W}_i$
(the Hessian of the regression objective is
$\Sigma_i \otimes I_{|\mathcal{A}|} \succ 0$),
and to bound
$\|\hat{W}_i\|_F$ via
$\|\Sigma_i^{-1}\|_{\mathrm{op}}
= 1/\lambda_{\min}(\Sigma_i) < \infty$.
Condition~(ii) is used to convert
parameter norm bounds to function value bounds.
Both conditions are standard in the linear
function approximation literature \citep{tsitsiklis1997analysis,bhandari2018finite}.
For HDC encoders with RBF random features,
condition~(i) holds whenever $\nu_i$ has a
Lebesgue density on $\mathcal{S}$
\citep{rahimi2007random}, and condition~(ii)
holds by normalising the feature vectors.

\end{assumption}


\begin{assumption}[Common RKHS]
\label{assum:common_rkhs}
There exists a continuous, symmetric, positive-definite kernel
$\kappa:\mathcal{S}\times\mathcal{S}\to\mathbb{R}$ with
$\kappa(s,s)\leq 1$ for all $s\in\mathcal{S}$, inducing a
separable RKHS $\mathcal{H}$ that is dense in $L^2(\nu_i)$
for all $i$, such that:
\begin{enumerate}[label=\textup{(\roman*)}]
    \item \textup{(RKHS norm bound)}
    $\|Q^*(\cdot,a)\|_{\mathcal{H}}\leq B < \infty$
    for all $a\in\mathcal{A}$;
    \item \textup{(Common embedding)}
    there exists $\gamma_0\leq\min_i\gamma_i$ such that
    all client function classes embed as
    $\mathcal{F}_i\hookrightarrow\mathcal{H}$,
    with the reproducing property
    $f(s)=\langle f,\kappa(\cdot,s)\rangle_{\mathcal{H}}$
    holding for all $f\in\mathcal{H}$, $s\in\mathcal{S}$.
\end{enumerate}
\end{assumption}

\begin{assumption}[Anchor set]
\label{assum:anchor}
The anchor set $\mathcal{S}_{\mathrm{ref}}=\{s_1,\ldots,s_m\}$
is drawn i.i.d.\ from a distribution $\nu_{\mathrm{ref}}$ with
$\nu_{\mathrm{ref}}\ll\nu_i$ for all $i$, and $\lambda>0$.
\end{assumption}

\begin{definition}
Given the regression oracle  $\hat{Q}_i(s,a)$ defined in Definition~\ref{def:oracle}, we 

define the \emph{federation gap} at any state-action pair $(s,a)$:
\begin{equation}
    \Delta_i(s,a)
    \;\defeq\;
    \hat{Q}_i(s,a)
    \;-\;
    Q_i\!\left(s,a;\,W^{\mathrm{glob}}_i(\lambda)\right),
    \label{eq:gap_def}
\end{equation}
where $Q_i(s,a;W^{\mathrm{glob}}_i(\lambda))
= \Re(\Phi_i(s)^{\mathrm{H}}W^{\mathrm{glob}}_i(\lambda)_{:,a})$
is the compiled FedQHD output.




To analyze the federation gap, we introduce $\bar{Q}(s,a) \defeq \sum_{i=1}^N \pi_i\hat{Q}_i(s,a)$
as the federation-weighted mean of the oracles, which serves as the global objective defined in~\ref{eq:qglob_avg}.


By the triangle inequality:
\begin{equation}
    |\Delta_i(s,a)|
    \;\leq\;
    \underbrace{|\hat{Q}_i(s,a) - \bar{Q}(s,a)|}_{
    \text{(A): Representation Bias}}
    \;+\;
    \underbrace{|\bar{Q}(s,a)
    - Q_i(s,a;\,W^{\mathrm{glob}}_i(\lambda))|}_{
    \text{(B): Aggregation Distortion}}.
    \label{eq:master_decomp}
\end{equation}
Term~(A) is a purely geometric quantity depending only on the
encoder subspaces and their principal angles.
Term~(B) captures how accurately FedQHD's anchor-set ridge
regression recovers the mean oracle; it is bounded through the
projection residual machinery of
Section~\ref{sec:projection_residual}.
\end{definition}

\begin{definition}[Pairwise heterogeneity cost]
\label{def:het_cost}
For clients $i,j$ with function subspaces
$\mathcal{F}_i,\mathcal{F}_j\subset\mathcal{H}$, define
\begin{equation}
    h_{ij}
    \;\defeq\;
    2B\sin(\theta_{ij})
    \;+\;
    \varepsilon_i^{\mathrm{rep}}
    \;+\;
    \varepsilon_j^{\mathrm{rep}},
    \label{eq:hij_def}
\end{equation}
where $\theta_{ij}$ is the largest principal angle
between $\mathcal{F}_i$ and $\mathcal{F}_j$ in
$\mathcal{H}$ (Definition~\ref{def:principal_angle})
and $\varepsilon_i^{\mathrm{rep}}
= \max_a\|(I-\Pi_i)Q^*(\cdot,a)\|_{\mathcal{H}}$
(Definition~\ref{def:oracle}).
The weighted heterogeneity cost for client $i$ is
$\bar{h}_i \defeq \sum_{j\neq i}\pi_j\,h_{ij}$.
For RBF random feature encoders of dimension $D_i$,
$h_{ij} = O(1/\sqrt{\min(D_i,D_j)})$.
\end{definition}

Recall the federation gap
(Definition~\ref{eq:gap_def}):
\begin{equation}
    \Delta_i(s,a)
    \;\defeq\;
    \hat{Q}_i(s,a)
    \;-\;
    Q_i(s,a;\,W^{\mathrm{glob}}_i(\lambda)),
\end{equation}
and the master decomposition~\eqref{eq:master_decomp}
into Term~(A) (representation bias) and
Term~(B) (aggregation distortion).

\subsubsection{Main Theorem}

\begin{theorem}[Federation gap bound]
\label{thm:fed_gap_main}
Under
Assumptions~\ref{assum:common_rkhs}--\ref{assum:qstar_l2},
with $\lambda > 0$, the federation gap satisfies for all
$s\in\mathcal{S}$, $a\in\mathcal{A}$:
\begin{equation}
\boxed{
    |\Delta_i(s,a)|
    \;\leq\;
    \underbrace{
    \bar{h}_i
    \vphantom{\frac{\sqrt{m}}{\sqrt{\gamma_i+\lambda}}}
    }_{\substack{\textbf{(I) encoder}\\\textbf{heterogeneity}}}
    \;+\;
    \underbrace{
    \frac{\sqrt{m}}
    {\sqrt{\gamma_i + \lambda}}\;
    \bar{h}_i
    }_{\substack{\textbf{(II) anchor}\\\textbf{amplification}}}
    \;+\;
    \underbrace{
    \frac{\lambda}
    {\gamma_i + \lambda}\;
    \hat{B}_i
    \vphantom{\frac{\sqrt{m}}{\sqrt{\gamma_i+\lambda}}}
    }_{\substack{\textbf{(III) ridge}\\\textbf{shrinkage}}}
}
\label{eq:gap_design}
\end{equation}
where:
\begin{align}
    \gamma_i
    &\;\defeq\;
    \sigma_{\min}(G_i),
    \quad
    G_i = X_i X_i^{\mathrm{H}}
    \in \mathbb{K}^{m \times m},
    \label{eq:gamma_def}\\
    \hat{B}_i
    &\;=\; \|\hat{W}_i\|_F
    \;\leq\;
    \frac{B\sqrt{m\,|\mathcal{A}|}}
    {\sqrt{\gamma_i}},
    \quad\text{when $\gamma_i > 0$}.
    \label{eq:Bhat_def}
\end{align}
\end{theorem}

\begin{proof}[Proof sketch]
Term~(I) follows from the triangle inequality and the RKHS pairwise bound
(Lemma~\ref{lem:pairwise_rkhs}), bounding the representation bias
as $\sum_{j\neq i}\pi_j h_{ij} = \bar{h}_i$.
Term~(III) follows from spectral analysis of
$(X_i^{\mathrm{H}} X_i + \lambda I)^{-1}$:
the oracle ridge shrinkage satisfies $(B_1) \leq [\lambda/(\gamma_i+\lambda)]\hat{B}_i$.
Term~(II) follows from the Woodbury identity and
Theorem~\ref{thm:invisibility}: only the in-subspace teacher component
enters the regression solution, and the resulting teacher mismatch is
bounded by $(\sqrt{m}/\sqrt{\gamma_i+\lambda})\bar{h}_i$.
Full derivations, including Lemma~\ref{lem:pairwise_rkhs} and all subterm bounds,
are given in Appendix~\ref{app:proof_fedgap}.
\end{proof}

\subsubsection{Interpretation}

The three terms have distinct roles and design levers:

\begin{enumerate}[label=\textbf{(\Roman*)}]
    \item \textbf{Encoder heterogeneity} $\bar{h}_i$:
    the irreducible cost of using different encoders,
    controlled by $D$
    ($\bar{h}_i = O(1/\sqrt{D})$ for RBF features).
    This term persists even with infinite anchors
    and zero regularisation.

    \item \textbf{Anchor amplification}
    $\frac{\sqrt{m}}{\sqrt{\gamma_i+\lambda}}\,
    \bar{h}_i$:
    the cost of transferring heterogeneity through
    anchor-set regression. Proportional to $\bar{h}_i$
    (no heterogeneity $\Rightarrow$ no amplification)
    and controlled by $m$, $\lambda$, and $\gamma_i$.

    \item \textbf{Ridge shrinkage}
    $\frac{\lambda}{\gamma_i+\lambda}\,\hat{B}_i$:
    the bias from regularisation.
    Controlled by $\lambda$ (smaller $\Rightarrow$
    less shrinkage), $m$ (more anchors improve
    $\gamma_i$), and $D$ (once $D_i$ crosses $m$,
    $\gamma_i$ jumps from zero to positive).
\end{enumerate}

Terms~(II) and~(III) are in tension through $\lambda$:
larger $\lambda$ reduces (II) but increases (III).

%───────────────────────────────────────────────────────────────
\subsubsection{Phase Transition at $D_i = m$}

The Gram matrix $G_i$ is $m \times m$ with
$\mathrm{rank}(G_i) = \min(m, D_i)$.
Its minimum eigenvalue $\gamma_i$ exhibits a
phase transition:

\begin{center}
\renewcommand{\arraystretch}{1.3}
\small
\begin{tabular}{lcc}
\toprule
 & $D_i \geq m$ & $D_i < m$ \\
\midrule
$\mathrm{rank}(G_i)$
 & $m$ (full rank)
 & $D_i$ \\
$\gamma_i$
 & $> 0$, $\to \sigma_{\min}(K_\infty)$ as $D_i\!\to\!\infty$
 & $= 0$ \\
Term (II)
 & $\frac{\sqrt{m}}{\sqrt{\gamma_i+\lambda}}\,\bar{h}_i$
   \;($\lambda$ can be small)
 & $\frac{\sqrt{m}}{\sqrt{\lambda}}\,\bar{h}_i$
   \;(reverts to original) \\
Term (III)
 & $\frac{\lambda}{\gamma_i+\lambda}\,\hat{B}_i
   < \hat{B}_i$
 & $\hat{B}_i$ \;(maximal, $\lambda$-independent) \\
\textbf{Bottleneck}
 & heterogeneity $\bar{h}_i$
 & capacity $\hat{B}_i$ \\
\bottomrule
\end{tabular}
\end{center}

When $D_i < m$, Term~(III) saturates at $\hat{B}_i$
regardless of $\lambda$, and adding more anchors
beyond $D_i$ only amplifies Term~(II) without
reducing Term~(III).
When $D_i \geq m$, $\gamma_i > 0$ and the ridge
can be made small, making the gap dominated by
the heterogeneity floor $\bar{h}_i$.

%───────────────────────────────────────────────────────────────
\subsubsection{Corollaries}

\begin{corollary}[Zero-gap conditions]
\label{cor:floor}
$|\Delta_i(s,a)|=0$ if and only if simultaneously:
\textup{(i)}~$\theta_{ij}=0$ for all $j\neq i$;
\textup{(ii)}~$\varepsilon_i^{\mathrm{rep}}=0$ for all $i$;
\textup{(iii)}~$\lambda\to 0$ and $D_i \geq m$.
\end{corollary}

\begin{corollary}[Homogeneous recovery]
\label{cor:homogeneous}
When $\Phi_i=\Phi$ for all $i$:
$\bar{h}_i = 0$, so
$|\Delta_i| \leq c_i(\lambda)\hat{B}_i \to 0$
as $\lambda\to 0$, $D \geq m$.
\end{corollary}

\begin{corollary}[Optimal regularisation]
\label{cor:optimal_lambda}
Balancing Terms~(II) and~(III) in~\eqref{eq:gap_design}
yields:
\begin{equation}
    \lambda^*_i
    \;=\;
    \left(
    \frac{\gamma_i\,\hat{B}_i}
    {\sqrt{m}\;\bar{h}_i}
    \right)^{2/3}.
    \label{eq:lambda_star}
\end{equation}
\end{corollary}

\begin{corollary}[Regime-specific scaling]
\label{cor:regimes}
\mbox{}

\noindent\textbf{Overparameterised ($D_i \geq m$,
$\gamma_i > 0$).}
Setting $\lambda \to 0$:
\begin{equation}
    |\Delta_i|
    \;\leq\;
    \left(1+\frac{\sqrt{m}}{\sqrt{\gamma_i}}\right)
    \bar{h}_i
    \;=\;
    O(\bar{h}_i)
    \;=\;
    O(1/\sqrt{D}).
    \label{eq:gap_over}
\end{equation}

\noindent\textbf{Underparameterised ($D_i < m$,
$\gamma_i = 0$).}
At optimal $\lambda^*_i$:
\begin{equation}
    |\Delta_i|
    \;\leq\;
    \bar{h}_i
    \;+\;
    O\!\left(
    m^{1/3}\,\bar{h}_i^{2/3}\,\hat{B}_i^{1/3}
    \right).
    \label{eq:gap_under}
\end{equation}
\end{corollary}
